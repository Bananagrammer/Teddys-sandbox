# Town Lamps

A first-person game. A boy starts in a small town. Four street lamps are out. Walk up to each one and light it.

## Run

```bash
npm install
npm run dev
```

Vite serves the game at `http://localhost:5173` and opens a browser.

## Controls

- **Keyboard:** WASD or the arrow keys walk. Click the view, then move the mouse to look. Esc releases the mouse. E lights a lamp when you are standing next to it.
- **Xbox controller:** standard gamepad mapping. The left stick walks, the right stick looks, and A lights a lamp. The sticks work without clicking the view.

## Finish

Light all four lamps around the plaza. The goal line at the top counts them. When the last one is lit, the streets are lit.
