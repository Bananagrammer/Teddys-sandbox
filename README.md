# Town Walk

A first-person walk. A boy starts in a small town. The street lamps around the plaza are already lit.

## Run

```bash
npm install
npm run dev
```

Vite serves the game at `http://localhost:5173` and opens a browser.

## Controls

- **Keyboard:** WASD or the arrow keys walk. Space jumps (the same jump as Xbox A). F toggles the chapel door when he is standing next to it: one press opens it, the next press closes it. Click the view, then move the mouse to look. Esc releases the mouse.
- **Xbox controller:** standard gamepad mapping. The left stick walks and the right stick looks. A jumps, and only when he is on the ground. X toggles the chapel door when he is standing next to it: one press opens it, the next press closes it. The sticks, A, and X work without clicking the view.
