# Town Walk

A first-person prototype. A boy starts in a small town. Walk and look around.

## Run

```bash
npm install
npm run dev
```

Vite serves the game at `http://localhost:5173` and opens a browser.

## Controls

- **Keyboard:** WASD or the arrow keys walk. Click the view, then move the mouse to look. Esc releases the mouse.
- **Xbox controller:** standard gamepad mapping. The left stick walks and the right stick looks. Sticks work without clicking the view.
