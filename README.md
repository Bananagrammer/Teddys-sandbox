# Town Walk

A first-person walk. A boy starts in a small town. The street lamps around the plaza are already lit.

## Run

```bash
npm install
npm run dev
```

Vite serves the game at `http://localhost:5173` and opens a browser.

## Controls

- **Keyboard:** WASD or the arrow keys walk. Space jumps. F toggles the nearest door (the chapel or house 48) when he is standing next to it: one press opens it, the next press closes it. Click the view, then move the mouse to look. Esc releases the mouse. Space is not the ladder climb.
- **Xbox controller:** standard gamepad mapping. The left stick walks and the right stick looks. Hold A in front of a ladder to climb (the tree house, the slide, or the play structure). Away from a ladder, A jumps, and only when he is on the ground; holding A does not chain jumps. X toggles the nearest door (the chapel or house 48) when he is standing next to it: one press opens it, the next press closes it. The sticks, A, and X work without clicking the view.
